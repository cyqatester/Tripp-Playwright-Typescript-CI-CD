UI automation for `https://www.tripp.co.uk/`, built with Playwright Test, TypeScript, Page Object Model (POM), and custom fixtures.

## Design

- **Page objects:** separate classes for Home, Cabin and Airlines, Suitcases, Travel Bags, Accessories, More / Products, and Your Basket.
- **Locators:** centralized in page-object classes.
- **Assertions:** defined in the `.spec.ts` test files.
- **Fixtures:** `fixtures/page-fixtures.ts` creates and exposes typed page objects to tests.
- **Configuration:** `playwright.config.ts` configures the base URL, Chromium project, HTML/JUnit reporters, and failure artifacts.

## Requirements

- Node.js 24 (used by CI; a compatible current Node.js release is recommended locally)
- npm

## Setup

Install the dependencies and the Chromium browser:

```bash
npm ci
npx playwright install chromium
```

Optional environment configuration:

```bash
cp .env.example .env
```

On Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

Set `BASE_URL` in `.env` to override the default `https://www.tripp.co.uk/` target.

## Run tests

```bash
npm test
npm run typecheck
```

Additional commands:

```bash
npm run test:headed
npm run test:ui
npm run test:debug
npm run report
```

Run an individual spec:

```bash
npx playwright test tests/home.spec.ts
```

## GitHub Actions CI

The workflow is located at `.github/workflows/playwright.yml`.

It runs automatically for:
- Pushes to `main` or `master`
- Pull requests targeting `main` or `master`

It can also be started manually from the repository's **Actions** tab using **Playwright CI → Run workflow**.

### CI job steps

1. Checks out the repository.
2. Sets up Node.js 24 and npm dependency caching.
3. Installs locked dependencies with `npm ci`.
4. Installs Chromium and its operating-system dependencies.
5. Runs `npm run typecheck`.
6. Runs the Playwright suite with `CI=true`.

The workflow uses the current major releases of the official GitHub Actions: `actions/checkout@v7`, `actions/setup-node@v7`, and `actions/upload-artifact@v7`. It also sets read-only repository contents permission and cancels superseded runs for the same branch or pull request.

### Test artifacts and reports

The workflow uploads `playwright-report/` and `test-results/` as an artifact named `playwright-results`, even if the test job fails. Artifacts are retained for 14 days.

To view a report:

1. Open the repository on GitHub and select **Actions**.
2. Open the relevant **Playwright CI** run.
3. Download `playwright-results` from the run's **Artifacts** section.
4. Extract the archive and open `playwright-report/index.html` in a browser.

The `test-results/` directory contains the JUnit report and Playwright failure artifacts such as traces, screenshots, and videos when generated by the configured test run.

No GitHub repository secrets are needed for the default public-site configuration. If you change `BASE_URL` to a protected test environment, configure any required credentials as GitHub Actions secrets and expose them to the workflow as environment variables.

## Important implementation notes

1. The homepage test checks for a visible logo image whose `src` ends with `/images/logo.png`. If the live site uses a different logo asset path, update `HomePage.logo`.
2. E-commerce websites can change navigation markup, labels, cookie banners, product availability, and basket behavior. Locators are centralized in page objects so adjustments remain localized.
3. The basket test adds an available item to the basket and does not submit an order or payment.
4. The quantity-decrement interaction depends on the control exposed by the live basket page. Keep its expected behavior aligned with the site's current implementation.
5. Tests do not attempt to bypass bot protection, CAPTCHA, queues, or access controls. If the site presents a verification challenge, use an authorized test environment or contact the site owner.

## Test inventory

The suite covers:
- Homepage loading and logo visibility
- Navigation/category checks for Cabin and Airlines, Suitcases, Travel Bags, Accessories, and More
- Products header and category navigation
- Product detail and Add to Basket visibility
- Add to Basket and Checkout Now visibility
- Navigation to Your Basket
- Basket quantity-decrement control visibility and interaction
